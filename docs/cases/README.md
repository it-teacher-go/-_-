**주제로 묶어 찾을 때** — 모바일 폭은 강의노트-화면의 「본문에 남는 폭」 · 「`table-prose`」, 용어 통일은 강의노트-서술의

시뮬레이터의 「시뮬레이터의 용어」에서 시작한다.
