### 2026-08-11 · 배포 산출물을 둘로 나누지 않는다

**로컬화를 하는 이유부터** — 학교망은 CDN을 막는 경우가 많다. 배포되는 사이트 자체가
로컬화된 번들이어야 **CDN을 막는 학교망에서도 수업이 된다.** 오프라인 zip은 덤이 아니라
같은 목적의 다른 배달 방법이다.

예전에는 Pages용(CDN 유지)과 릴리즈 zip용(로컬화)을 따로 만들었다.
**zip은 아무도 열어 보지 않아 결함이 그쪽에만 쌓였다.**

실제로 `프로그래밍(Python)/1-1-2`에서 런타임에 조립된 클래스 8개 중 **3개가 zip에서만 빠진 채**
오래 남아 있었다. 소스를 그대로 열면 CDN 런타임 JIT라 멀쩡히 보이므로 눈으로는 잡히지 않았다.

같은 파일을 서빙하면 **사이트를 보는 사람이 곧 번들의 검증자가 된다.**
2026-08-11에 하나로 합쳤다.

**그래도 「같은 파일」이 「같게 동작한다」는 뜻은 아니었다.** 합친 뒤에도 zip에서만
깨지는 것이 남아 있었다 — `<script type="module">`이다. 모듈은 CORS를 타는데
`file://`의 출처는 `null`이라 브라우저가 무조건 거절한다. 라이브러리가 실리지 못해
시뮬레이터의 그래프·트리·차트가 통째로 안 그려졌는데, **사이트에서는 멀쩡했다.**
2026-08-19에 빌드가 평범한 스크립트로 눌러 담게 고치고, 모듈이 다시 새어 나가면
`check -- dist`가 CI를 세우게 했다. **배달 방법이 둘이면 검사도 둘 다를 봐야 한다.**

### 2026-08-11 · CDN에서 npm + Vite로 — 밟은 함정

2026-08-11에 소스 HTML의 CDN을 전부 걷어냈다. 옮기는 것 자체보다 **옮긴 뒤에
조용히 깨지는 것**을 찾는 데 시간이 들었다.

| 함정 | 어떻게 드러났나 |
|---|---|
| **npm 판과 CDN 판의 API가 다르다** | lucide UMD는 `createIcons()`만으로 됐지만 npm 판은 아이콘 목록을 받는다. 콘솔 오류가 나서 바로 잡혔다 |
| **최상위 `await`는 `window.onload`보다 늦다** | Prism 언어 확장을 동적 import로 붙였더니 하이라이팅이 **조용히** 실패했다. 오류도 없고 토큰만 0이었다 |
| **전역에 얹는 순서가 있다** | Prism 언어 확장은 전역 `Prism`이 선 뒤에 평가되어야 한다. 진입점에서 `_lib/prism.js`를 먼저 `import` 하는 정적 순서로 맞췄다 |
| **모듈은 defer라 인라인 스크립트보다 늦다** | 인라인에서 라이브러리를 바로 부르는 파일을 찾아야 했다. **들여쓰기로 세면 48개, 괄호 깊이로 세면 1개** — 앞의 것은 `window.onload` 안까지 센 과대추정이었다 |
| **버전을 안 맞추면 조용히 깨진다** | npm 기본이 Font Awesome 7(아이콘 이름 변경), p5 2.x(호환 깨짐)였다. **소스가 쓰던 CDN 주소의 버전으로 못박았다** |

**되는지는 브라우저로만 확인된다.** 클래스 대조와 링크 검사는 전부 통과했는데도
하이라이팅이 죽어 있었다. 라이브러리를 옮겼으면 대표 페이지를 실제로 띄워 본다.

**클래스를 코드로 조립하지 않는 까닭** — 빌드는 리터럴로 있는 클래스만 굽는다. `bg-${x}-50`은
CSS에서 빠지는데 dev에서는 멀쩡히 보인다. **JS 문자열에 적은 Tailwind 클래스도 같다**(2026-09-25
사용자 확정). Tailwind는 HTML만 읽고 `src/entries/`의 JS는 읽지 않아, JS에 적은 클래스는 같은 것이
우연히 HTML에 있을 때만 살았다 — CDN 시절 런타임이 다 구워 주던 흔적이다. 그래서 JS에는 뜻을 가진
이름만 적고 모양은 CSS에서 `@apply`로 준다. `check -- classes`가 Tailwind에게 직접 구워 보게 해서 잡는다.

→ 규칙: docs/강의노트-작성-규칙.md 「빌드와 의존성」

### 2026-09-25 · 명령은 한 곳에서 정의한다

CI도 IDE 실행 구성도 `npm run` 이름만 부르므로 `package.json`(검사·감사는 `tools/run.mjs`)
한 곳만 고치면 셋이 함께 바뀐다. 로컬과 CI가 같은 한 줄 `npm run ci`를 돌므로 로컬에서 초록이면
CI도 초록이다. 터미널에서 부르면 특정 편집기에 매이지 않는다.

- **헷갈리는 이름** — `sim`과 `sims`가 나란히 있던 적이 있다.
- **파이썬 검사를 들이지 않는 까닭** — 2026-09-25 사용자 지시로 검사를 전부 Node/Vitest로 옮겼다.
- **fixtures를 함께 넣는 까닭** — 저장소가 깨끗하면 「위반 0」은 검사가 망가졌을 때도 똑같이 나온다.
- **돌연변이를 더하는 까닭**(2026-09-25 사용자 지시) — 오류를 못 잡으면서 초록인 검사는 없는 것보다
  나쁘다. 첫 전수 돌연변이에서 넷이 살아남았다 — 경사 하강 학습기 · 설명문의 개수 · CSS의 `fs-on`은
  아무 검사도 보고 있지 않았다. 오래 걸려 `ci` 밖에 둔다.

### 2026-08-27 · 문서와 주석이 낡는 까닭

산문은 고쳐도 CI가 보지 않으므로 **조용히 거짓이 된다.**

- 「위반 0건」·「146개를 굽는다」는 적는 순간 썩기 시작한다. 결과는 도구가 출력할 자리다.
- 「소스에 CDN이 없다」고 적으면 낡지만, 「`check -- dist`가 CDN 잔존 0을 보증한다」고 적으면
  낡을 수가 없다 — 보증이 바뀌면 CI가 빨간불이 되기 때문이다.
- 날짜가 있으면 독자가 「틀린 말」이 아니라 **「옛날 말」**로 읽고 알아서 할인한다.
- 줄 번호 · 형제의 개수 · 차례는 한 줄만 끼워 넣어도 전부 어긋나는데 **어긋난 것을 아무도 알려
  주지 않는다**(2026-08-27 사용자 확정). 이름은 바꾸면 코드가 먼저 깨지므로 고치지 않고는 지나갈 수 없다.
- 도구 사용법을 README와 머리 주석 두 군데에 적으면 **반드시 갈라진다**(2026-09-26 사용자 확정).
  정리해 보니 README가 코드와 이미 어긋난 곳이 둘 있었다.

### 2026-09-25 · 브라우저 도구를 묻고 쓰는 까닭

Claude 브라우저 도구는 토큰을 많이 먹고 오래 걸린다. 375px 실측의 예외를 없앤 경위는 [강의노트 화면 판례](강의노트-화면.md) 「섹션 하나는 375px에서 6화면을 넘지 않는다」.

`check -- layout`은 2026-09-25 사용자 지시로 세웠다. headless Chromium으로 375px · 전체 화면
1366/1920에서 넘침 · 조작 겹침 · 스크롤해도 닿지 않는 조작을 본다. Claude 브라우저 도구가 아니므로
묻지 않고 돌리고, `ci`에 들어 있다.

### 2026-08-05 · 커밋 메시지로 검토를 요청하려다 반려됨

밤새 여러 강의노트를 만들고 아침에 `git log`로 판단 거리를 전하는 방식을 제안했다가 반려됐다. 커밋 이력은 나중에
읽는 사람에게 변경 근거를 설명하는 곳이지 끝난 검토 요청이 남을 곳이 아니다. 그래서 강의노트는 한 편씩 사용자 확인을
받고, 판단이 갈린 것은 채팅으로 보고한다. 피드백 없이 찍어 내면 같은 실수가 그대로 복제된다 — 표 찌그러짐이 지적받기 전까지
두 파일에 이미 복제되어 있었다.

→ 규칙: CLAUDE.md 「커밋과 배포」

### 2026-09-24 · 서브에이전트를 여섯 개 동시에 띄웠다가 막힘

diff 감사를 여섯 개 동시에 띄우자 사용자가 「동시에 돌리지 말 것. 토큰이 부족하다」고 막았다. 그 뒤 한 번 병렬을 요청받았다고
다음 작업까지 병렬로 일반화하지 않는다는 것도 함께 정했다. 하위 에이전트 지시문에 「하위 에이전트를 띄우지 않는다」를
넣지 않았더니 에이전트가 파일마다 일곱 개를 병렬로 띄운 적이 있다.

→ 규칙: CLAUDE.md 「작업 방식」

### 2026-09-24 · 강의노트 이름 변경이 엉뚱한 커밋에 딸려 감

소프트웨어와 생활 정제 때 에이전트가 `git mv`를 스테이징해 둔 탓에 이름 변경이 다른 커밋에 들어갔고, 푸시 전에 커밋을
다시 지어야 했다. 이름을 바꾸면 `index.html`의 링크도 함께 바뀌어야 하므로 한 커밋에 담는다. 같은 무렵 `check -- index-links`를 세웠다.

### 2026-09-25 · git으로 파일을 되돌리는 것을 막음

문체 정제 중 사용자가 기존 작업이 날아가는 것을 걱정해 `git checkout` · `restore` · `reset`으로 파일을 되돌리지 말고,
틀리면 새 수정으로 덮으라고 정했다. 에이전트에게는 git 쓰기를 맡기지 않는다.

### 2026-09-25 · 「정제는 끝났다」고 답했다가 품질 기준을 다시 들음

과목 간 점검을 마치고 「끝났다」고 답하자 사용자가 기준을 상용 유료 교재 수준으로 못박았다. 점검할 때마다 새 결함이 나왔고,
고친 문장 자체는 다시 읽히지 않은 채였다. 그래서 끝났다고 말하기 전에 바뀐 문장의 diff를 다시 읽는다.

### 2026-09-26 · 판단 거리를 모아 표로 물음

사용자가 자는 동안 작업을 이어 가며 판단이 필요한 것은 모아 두었다가 한 번에 물었다. 항목 · 걸리는 점 · 추천안을 한 표로

### 2026-09-27 · 문서를 규칙 · 판례 · 기기 환경으로 가름
