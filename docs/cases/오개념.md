### 2026-08-05 · 인과 화법

```
X  키가 1 cm 커질 때 몸무게가 1.648 파운드 늘어난다
O  키가 1 cm 더 큰 선수가 몸무게는 평균 1.648 파운드 더 나가는 경향이다
```

`커질 때 ~ 늘어난다`는 **한 개체가 변화한다**는 뜻으로 읽혀 인과가 된다.
**직접 조작한 실험**이라면 인과 화법이 정당하다(물의 양을 바꿔 가며 준 화분 실험 등).

**독립·종속 변수를 지정하는 문장이 단골 구멍이다.** 독립 변수 쪽만 가정을 밝히고
종속 변수 쪽은 단정하기 쉽다.

```
X  공부 시간에 따라 점수가 변하므로 종속 변수입니다
O  점수가 공부 시간에 따라 달라진다고 보고 분석하므로 종속 변수입니다

X  3시간 30분 공부하면 70점 나오겠네        ← 한 학생이 공부량을 바꾸는 것으로 읽힌다
O  공부 시간이 3시간 30분인 학생이라면 70점쯤 되겠네
```

### 2026-08-05 · 조건부 사실의 무조건화 — 가장 많이 걸린다

```
X  결정계수는 비율이므로 언제나 0에서 1 사이입니다
   → 같은 파일의 실습 안내가 「R²이 음수로 나왔다면 놀라지 마세요」라 모순이 난다
O  모델을 만들 때 쓴 데이터로 재면 0에서 1 사이이고,
   본 적 없는 데이터로 채점하면 0보다 작아질 수도 있습니다
```

**한 파일 안에서 앞뒤가 어긋나는 것**이라, 새 파일을 쓴 뒤
**도입부의 단정 문장과 실습·결론을 나란히 놓고 읽어야** 잡힌다.

방법 하나만 옳은 것처럼 쓰는 것도 같은 유형이다 —
`실루엣은 평균이 가장 큰 k를 고르면 된다`(`3-3-3`의 결론은 유보하고 있었다),
`회귀 분석에서는 정규화를 하지 않아도 된다`(계수로 맞춰지는 것은 **선형 회귀**뿐이고,
같은 파일이 회귀에 써 본 k-최근접 이웃은 거리를 재므로 정규화가 필요하다).

2026-08-05 데이터과학에서 세 파일이 같은 모양이었다 — `3-2-3`(결정계수 범위),
`2-1-2`(「개수가 많아 대표한다」 ↔ 몇 화면 뒤 「많이가 아니라 고르게」),
`2-3-2`(「통계로는 안 보이고 시각화로만 보인다」 ↔ 바로 위 자기 평균 표).

**2026-08-06에 드러난 새로운 모양 — 앞 파일이 조건부로 세운 것을 뒤 파일이 되돌린다.**
